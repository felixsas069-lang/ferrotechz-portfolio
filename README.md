FERROTECHZ | Felix Nyabuti Nyamoi — Portfolio Website

FILES
- index.html: complete responsive static website. No build step or paid libraries required.

BEFORE PUBLISHING
1. Open index.html in VS Code or a text editor.
2. Near the bottom, find:
   const CONTACT_EMAIL = "felixsas069@gmail.com";
   const WHATSAPP_NUMBER = "254781126223";
3. Replace the email placeholder with an email address you control.
4. Replace the WhatsApp placeholder with your international number using digits only, including country code (Kenya starts with 254; omit the +).
5. Save. Do not publish private information you do not want public.
6. Review project status and wording so they accurately reflect what you can show.

TEST LOCALLY
- Double-click index.html to open it in your browser; or use VS Code Live Server.
- Check mobile width, navigation, project sections, and contact form.
- The contact form opens a draft email after a real email address is configured. It does not send/store form submissions on a server.

FREE DEPLOYMENT: GITHUB PAGES
1. Create/sign in to GitHub: https://github.com/
2. Create a new public repository named `felixnyabuti.github.io` (or choose a different name; the URL will differ). Use your own available username in place of `felixnyabuti`.
3. Upload `index.html` to the repository root using Add file > Upload files, then commit the change.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch. Select `main` and `/(root)`, then Save.
6. Wait a few minutes. GitHub Pages will show the published URL in Settings > Pages. For a user site it is usually `https://YOUR-USERNAME.github.io/`; for another repository it is usually `https://YOUR-USERNAME.github.io/REPOSITORY/`.
7. Open the published URL and test it on your phone and laptop.

IMPORTANT
- This portfolio is a static website; it needs no paid hosting or server.
- A custom domain is optional and costs money; do not buy one unless you choose to.
- GitHub Pages hosting does not create a LinkedIn account and may not be accepted by Corpshore as its required professional-profile field. If they accept an equivalent portfolio URL, use your published website URL.
- Never put passwords, ID numbers, private documents, or other sensitive information in a public repository.
